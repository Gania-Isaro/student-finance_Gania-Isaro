# Student Finance Tracker

This is a simple tool for students to track their money. It works on phones and computers. It helps you see how much you earn and how much you spend.

## What it does
- See your balance, income, and expenses on one page.
- List all your transactions and search through them.
- Add and change transactions easily.
- Change currency to RWF, USD, EUR, or GBP.
- Set a monthly limit for your spending.
- Set a target for how much you want to save.

## How it's made
- It uses HTML for the structure.
- It uses CSS for the design and colors.
- It uses JavaScript for the logic and math.
- Everything is stored on your computer alone.

## Project Files
- index.html: The main page.
- styles/: Folder with design files.
- scripts/: Folder with math and logic files.
- seed.json: Example data you can use.

## How to use it
1. Open index.html in your browser.
2. Add your transactions using the form.
3. Check the dashboard to see your progress.

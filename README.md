# Student Finance Tracker
This is a tool for students to track their money. It works on phones and laptops. It helps you see how much you earn and how much you spend.
## Features
- See your income and expenses on one page.
- List all your transactions and search for them.
- Add and change transactions easily.
- Support for different currencies like RWF, USD, EUR, and GBP.
- Set a monthly limit for your spending.
- Set a goal for how much you want to save.
## How it is Made
- HTML: Used for the parts of the page.
- CSS: Used for colors and how the page looks.
- JavaScript: Used for math and the logic of the app.
- Local Storage: Your data is saved only on your own computer.
## File Structure
- index.html: The main file you open.
- styles/: This folder has the design files.
- scripts/: This folder has the logic and math files.
- seed.json: This file has example data you can use to test.
## How to Start
1. Open index.html in any web browser.
2. Add your income or expenses using the form.
3. Use the dashboard to see your savings and balance.
## Information for Developers
### Validation Rules (Regex)
- Description: No empty spaces at the beginning or end.
- Amount: Must be a positive number with up to 2 decimal places.
- Date: Must follow the Year-Month-Day format (YYYY-MM-DD).
- Category: Only letters are allowed.
- Repeat Check: It checks if you typed the same word twice (like "Food Food").
### Keyboard Shortcuts
- Tab: Move to the next button or link.
- Shift + Tab: Move to the previous button or link.
- Enter: Click a selected button.
- Esc: Use this to cancel when you are editing a row.
### Accessibility Features
- Clear Labels: Every part of the app has a clear label.
- Screen Reader Support: Changes in the budget will be announced to screen readers.
- Skip Link: You can jump to the main content quickly.
- Good Contrast: Colors are easy to see for everyone.
### Testing the App
Open the file named tests.html in your browser. It will automatically check if the app's logic is working correctly.
